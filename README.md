# Smart Expense Tracker and Analyzer

## Project Description

Smart Expense Tracker and Analyzer is a web-based financial management application developed using Flask and SQLite. The system allows users to manage expenses, income, savings goals, and monthly budgets while providing graphical analysis and financial insights.

The project helps users monitor spending habits, track financial goals, and improve money management through an easy-to-use interface.

## Installation / Execution Steps

1. Install Python 3.x

2. Install required packages

pip install flask werkzeug

3. Open project folder

4. Run application

python app.py

5. Open browser and visit

http://127.0.0.1:5000

6. Register a new account and start using the application.
